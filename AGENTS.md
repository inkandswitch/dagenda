# Agents

Skills for this repo are in [`.agents/skills/`](.agents/skills/), in the [Agent Skills](https://agentskills.io) format (`SKILL.md`). Agents that support skills find them there; Claude Code finds them through `.claude/skills`, a link to the same place.

| Skill                                         | Use it to                                                                 |
|-----------------------------------------------|---------------------------------------------------------------------------|
| [`dagenda`](.agents/skills/dagenda/SKILL.md)  | Read, write, check, and render dagenda plans, as `.dagenda` files or as a shared workspace (`automerge:` URL) |

If your agent doesn't load skills, read the `SKILL.md` before working on a plan.
